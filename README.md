# Project Terminator

## Project Overview

Project Terminator is a hands-on IT infrastructure project based on CompTIA A+ Core 2 (220-1202), focused on building, managing, securing, and troubleshooting the IT environment of a simulated company.

The project combines Windows and Linux administration, networking, cybersecurity, server management, and real-world IT support scenarios.

## Objectives

The main goal of this project is to turn my theoretical knowledge into practical skills and gain a better understanding of real-world IT environments.

- Build and maintain a functional IT infrastructure.
- Manage operating systems, servers, users, and permissions.
- Diagnose and resolve technical problems.
- Implement security measures.
- Automate administrative tasks.
- Develop professional troubleshooting and technical documentation skills.

## Company Structure

The simulated company will consist of four departments:

- IT
- Accounting
- Marketing
- Management

Each department will have its own users, groups, shared resources, and access permissions.
